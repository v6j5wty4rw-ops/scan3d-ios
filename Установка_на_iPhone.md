# Установка «3D Сканер» на iPhone (без Mac, бесплатный Apple ID)

Файл приложения: `Сборки\Scan3D-ipa\Scan3D.ipa`.
Новые сборки: https://github.com/v6j5wty4rw-ops/scan3d-ios/actions → последний запуск → артефакт `Scan3D-ipa`.

## Один раз
1. Установить iTunes с сайта Apple (не из Microsoft Store) — нужен драйвер iPhone для Windows. Если iTunes из Store уже стоит, Sideloadly может не увидеть телефон.
2. Скачать и установить Sideloadly: https://sideloadly.io (стороннее бесплатное приложение).
3. Подключить iPhone кабелем, на телефоне нажать «Доверять этому компьютеру».

## Установка
1. Запустить Sideloadly, в поле «Apple ID» ввести свой Apple ID.
2. Перетащить `Scan3D.ipa` в окно Sideloadly, нажать «Start».
3. Ввести пароль Apple ID в окне Sideloadly (если включена двухфакторная защита — код с телефона).
4. На iPhone: Настройки → Конфиденциальность и безопасность → Режим разработчика → включить, перезагрузить телефон, подтвердить.
5. На iPhone: Настройки → Основные → VPN и управление устройством → ваш Apple ID → «Доверять».
6. Запустить «3D Сканер», разрешить доступ к камере.

## Раз в 7 дней
Бесплатная подпись действует 7 дней. Повторить пункты 1–3 из «Установки» (сканы на телефоне сохраняются, если не удалять приложение).

## Где файлы сканов
Приложение «Файлы» → На iPhone → 3D Сканер → Scans → папка скана → Export. Файлы STL, OBJ, PLY — в миллиметрах.
