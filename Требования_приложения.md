# Приложение 3D-сканирования для iPhone — требования

Дата: 07.11.2026. Цель: сканирование деталей от малых до крупных для реверс-инжиниринга (SolidWorks).

## Исходные условия
- Телефон: iPhone 16 Pro Max, iOS 27.3.
- Mac нет. Сборка в облаке (GitHub Actions, macOS), установка с Windows через Sideloadly.
- Бесплатный Apple ID: приложение переустанавливать раз в 7 дней.
- ПК для метода 4: ноутбук с NVIDIA GeForce RTX 4050 Laptop, 6 ГБ (проверено nvidia-smi). Для Meshroom/COLMAP подходит; на очень больших сериях фото 6 ГБ может не хватить (оценка, не проверено).
- Резерв: Mac коллеги (есть Claude). Нужен для отладки на телефоне через Xcode, если облачная сборка запускается, но падает на устройстве. Симулятор камеру и LiDAR не имеет, сканирование в нём не проверить.

## Выбор метода сканирования (экран выбора при старте нового скана)

| № | Метод | Для чего | Как работает | Точность |
|---|---|---|---|---|
| 1 | Предмет — фотограмметрия (Object Capture, режим объекта) | Мелкие и средние детали | Обход вокруг детали, фото + LiDAR, модель собирается на телефоне | Лучшая из методов на телефоне (оценка, не проверено) |
| 2 | Область — Object Capture, режим области | Крупные детали, узлы на месте | То же, но без требования обойти со всех сторон | Средняя (наличие режима в iOS 27 — проверить при сборке) |
| 3 | LiDAR-сетка (ARKit) | Крупное оборудование, помещения, быстрая привязка габаритов | Сетка строится в реальном времени | Грубая, около 1 см (не проверено) |
| 4 | Фото для ПК | Крупные объекты с высокой точностью | Съёмка серии фото с данными камеры и глубины, сборка модели на ПК (Meshroom / COLMAP) | Высокая, зависит от съёмки и ПК (Meshroom требует NVIDIA) |

На экране выбора у каждого метода — короткая подсказка «для чего подходит».

## Общие функции
- Реальный масштаб модели (в мм) по данным LiDAR.
- Экспорт: STL, OBJ, PLY, USDZ; для метода 4 — папка фото (ZIP).
- Передача файлов: «Файлы», AirDrop, общий доступ.
- Список сохранённых сканов с названием, датой и методом.
- Предложение (не утверждено): линейка на готовой модели — расстояние между двумя точками в мм.

## Порядок работ
1. Репозиторий GitHub + облачная сборка .ipa.
2. Метод 1 (основа — пример Apple Object Capture), экспорт.
3. Методы 3 и 4.
4. Метод 2 (если режим доступен).
5. Проверка на телефоне по каждому методу.
